# 판례 근거 확인

입력: `$ARGUMENTS`

1. 사건번호 모양(연도+부호+번호)이면 `taxlens_get_precedent(case_no)`를 바로 부른다.
   `found=false`면 `taxlens_search_precedents(q=입력)`으로 실재 표기를 찾아 다시 부른다. 그래도 없으면 legal-kb `get_decision`을 본다.
2. 검색어면 `taxlens_search_precedents(q=입력)`를 부르고, 세목이 드러나면 `tax_type`을 함께 넣는다.
   상위 결과 중 질문에 맞는 1~3건을 `taxlens_get_precedent`로 읽는다.
3. 전문이 잘렸고(`next_offset_chars`) 판단 이유가 뒤에 있으면 `offset_chars`로 이어 읽는다.
4. 사건이 해석한 조문은 legal-kb `get_article`로 원문을 확인해 함께 인용한다.

출력: 사건번호 + 결정일 + 기관 + 결과 머리줄, 요지, 판단 이유 발췌, 연결된 과세표준 규칙(링크), 원 화면 링크.
도구가 돌려주지 않은 내용을 채우지 않는다.
