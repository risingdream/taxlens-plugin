# 필지 검토

대상: `$ARGUMENTS`

1. 19자리 숫자면 그대로 `taxlens_get_parcel(pnu)`를 부른다.
   주소면 시군구를 뽑아 `taxlens_search_properties(region, search=주소)`로 PNU를 찾은 뒤 부른다. 후보가 여럿이면 사용자에게 고르게 한다.
2. `found=false`면 번호를 확인하라고 알리고 멈춘다. 비슷한 번호를 추측하지 않는다.
3. 정리 순서: 주소·PNU → 토지(지목·면적·공시지가) → 소유(구분·이름 공개 여부·최근 변동) → 실거래 매칭(일자·금액·점수)
   → 건축물 → 인허가·정비구역.
4. 환급 가망을 물으면 필지가 속한 지역으로 `/taxlens:가망 <지역>`을 안내한다(필지 한 건 환급 판정 도구는 없다).

소유구분이 법인·종중·종교단체인데 소유자가 「미조회」면 `taxlens_lookup_owner(pnu)`로 등기부 소유자를 조회해 붙인다(한 필지라 상한 걱정 없음).
도구가 돌려주지 않은 값(연도별 공시지가)은 쓰지 않는다. 필요하면 택스렌즈 화면에서 확인하라고 안내한다.
